# Flowcharts

This document describes the main flows of **Room Up** (working title).
Each diagram is shown as an image (`docs/diagrams/*.png`, generated by `docs/diagrams/src/flowcharts.py`).
A [Mermaid](https://mermaid.js.org/) version of every diagram is kept under it as a text source.

**Legend**

| Shape | Meaning |
|---|---|
| Black, rounded | Start / end of a flow |
| Blue rectangle | Screen or action |
| Yellow diamond | Decision (yes / no question) |
| Red rectangle | Ends the round |
| Arrow label | Button the player taps, or the answer to a decision |

## 1. Screen Navigation

How the player moves between screens.

![Screen Navigation](diagrams/navigation.png)

<details>
<summary>Mermaid source</summary>

```mermaid
flowchart TD
    Launch([App launch]) --> Load[Load save data]
    Load --> Room[Room View]

    Room -- "Edit" --> Edit[Edit Mode]
    Edit -- "Inventory" --> Inv[Inventory]
    Inv -- "Pick item" --> Edit
    Inv -- "Close" --> Edit
    Edit -- "Done" --> Room

    Room -- "Shop" --> Shop[Shop]
    Shop -- "Back" --> Room

    Room -- "Play" --> Mode[Mode Select]
    Mode -- "Back" --> Room
    Mode -- "Classic" --> Puzzle[Puzzle Round]
    Puzzle -- "Board full" --> Results[Round Results]
    Results -- "Play again" --> Puzzle
    Results -- "Home" --> Room
```

</details>

> Progress is saved automatically after every purchase, every furniture change and every finished round.

## 2. Puzzle — One Move

What happens when the player tries to connect two items.

![Puzzle — One Move](diagrams/one-move.png)

<details>
<summary>Mermaid source</summary>

```mermaid
flowchart TD
    Wait([Wait for input]) --> Press[Player presses a cell]
    Press --> HasItem{"Is there an item?"}
    HasItem -- "No" --> Wait
    HasItem -- "Yes" --> Start[Start dotted line]

    Start --> Action{"Finger moved or released?"}
    Action -- "Moved" --> CanEnter{"Next cell empty or same type?"}
    CanEnter -- "Yes" --> Extend[Extend line]
    Extend --> Action
    CanEnter -- "No" --> Action

    Action -- "Released" --> Same{"Released on same type?"}
    Same -- "No" --> Cancel[Remove line]
    Cancel --> Wait

    Same -- "Yes" --> Match[Match pair]
    Match --> Neighbours{"Uncaptured same-type neighbours?"}
    Neighbours -- "Yes" --> Capture[Capture neighbours]
    Capture --> Neighbours
    Neighbours -- "No" --> Remove[Remove matched and captured items]
    Remove --> Coins[Add coins]
    Coins --> Wait
```

</details>

## 3. Puzzle — Spawn Tick

Runs on a timer, independently from the player's moves. This is the only flow that ends a round.

![Puzzle — Spawn Tick](diagrams/spawn-tick.png)

<details>
<summary>Mermaid source</summary>

```mermaid
flowchart TD
    Timer([Spawn timer fires]) --> Full{"Is there an empty cell?"}
    Full -- "No" --> EndRound[End round]
    EndRound --> Results([Show Round Results])

    Full -- "Yes" --> Helper{"Helper spawn roll (30%) succeeded?"}
    Helper -- "No" --> Random[Spawn random type in random empty cell]
    Helper -- "Yes" --> Stuck{"Stuck item with an empty neighbour?"}
    Stuck -- "No" --> Random
    Stuck -- "Yes" --> Near[Spawn same type next to the stuck item]

    Random --> Restart([Restart spawn timer])
    Near --> Restart
```

</details>

*A **stuck item** is an item that currently cannot be connected to any item of the same type.*
